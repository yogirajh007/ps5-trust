# The PlayStation 5 Trust

A simple, responsive GitHub Pages website presenting the proposed founding charter for the PlayStation 5 Trust. It uses readable document layouts, system fonts, and plain HTML and CSS, with no JavaScript, external font downloads, or decorative graphics.

## Pages

- `index.html` — a concise overview of the purpose, governance, acquisition fund, and gaming access rules.
- `constitution.html` — the full proposed constitution, with a table of contents and signature section.
- `styles.css` — shared typography, responsive layouts, accessibility, and print styles.
- `.github/workflows/pages.yml` — deploys the static site from `main` to GitHub Pages.

Both pages include navigation for keyboard users. The constitution can be printed directly from the browser.

## Publish

Push this directory to the repository's `main` branch, then select GitHub Actions as the Pages build and deployment source in repository settings. The included workflow publishes the site on each push to `main`.

The site is static and does not run an actual auction or collect funds. The ₹5,999 figure is an indicative target carried from the supplied draft; confirm the price before purchase. The charter is presented as a proposed private members’ agreement, not legal advice or an assertion that a statutory trust has been formed.
